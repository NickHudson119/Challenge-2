A little about me

Curiosity meets
quality.

My journey into software development started with a front-end coding bootcamp, where I learned HTML, CSS, and JavaScript while building my own projects. That experience gave me a foundation in how websites are built and sparked my interest in understanding how to make them work reliably.

More recently, I've been building my skills in software testing and automation through an SDET mentorship. I've gained hands-on experience with Playwright, TypeScript, UI and API testing, Page Object Model, reusable fixtures, and data-driven testing while developing automated testing frameworks.

What I enjoy most about QA is the problem-solving side of it. I like digging into how applications work, identifying potential issues, and finding ways to improve software quality. I'm excited to continue growing as a QA professional and contribute to building software people can depend on.
