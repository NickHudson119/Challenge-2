# Nicholas Hudson | QA Automation Portfolio

A responsive personal portfolio introducing Nicholas Hudson and his developing focus
in QA software testing and automation engineering. The site uses semantic HTML, CSS,
and a small amount of vanilla JavaScript; it does not require a framework or build step.

## Preview

Open `index.html` in a browser or serve the project directory with a local static
server. The site includes:

- Home and About Me
- Technical Skills
- Featured Projects
- Resume
- Contact

## Project structure

```text
index.html
assets/
  style.css
  script.js
  images/
```

## Final pre-deployment checks

- Confirm personal, contact, and resume details are intended for public access.
- Verify the project description, report screenshot, and GitHub destination.
- Test the site using the GitHub Pages project path `/Challenge-2/`.

The existing headshot is used in the hero. The existing logo asset has a white
background that does not suit the dark design, so the page uses a text-based monogram
instead.
